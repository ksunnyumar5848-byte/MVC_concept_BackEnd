🚀 MVC Architecture Backend Project
A backend application built using Node.js, Express.js, MongoDB, and Mongoose following the MVC (Model-View-Controller) architecture.

This project demonstrates Authentication, Authorization, Middleware, Password Hashing, JWT, Routing, Controllers, Database Integration, and REST API Development.

📌 What is MVC?
MVC stands for Model - View - Controller.

MVC is a software design pattern that separates application logic into three different layers.

Model
Handles Database Logic
Interacts with MongoDB
Manages Business Logic
View
Handles UI Layer
Displays Data to Users
Controller
Handles Requests and Responses
Connects Models and Views
Contains Application Logic
🎯 Why MVC?
Without MVC:

Code becomes difficult to manage
Business logic gets mixed everywhere
Difficult to debug
Difficult to scale
With MVC:

Clean Code Structure
Better Maintainability
Easy Team Collaboration
Reusable Components
